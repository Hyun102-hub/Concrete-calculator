# 인공신경망(ANN)과 콘크리트 강도 공식을 결합한 목표 강도 달성 확률 예측 시스템

배합(재료 7종 단위량)과 목표 강도, 재령(기본 28일)을 넣으면 그 재령에서 압축강도가 **목표 강도 이상일 확률**을 계산합니다.

## 공식 결합

- W/C = 물 ÷ 시멘트, W/B = 물 ÷ (시멘트 + 고로슬래그 + 플라이애시)
- Abrams 법칙 f = A ÷ B<sup>W/B</sup>, 학습용 데이터로만 맞춤: **A = 122.32, B = 11.980**
- ACI 209 재령 계수 g(t) = t ÷ (4 + 0.85t), 공식 예측 강도 = Abrams 28일 강도 × g(t) ÷ g(28)
- 공식 결합 ANN 입력 12개: 재료 7종 + 재령 + W/C + W/B + 재령계수 + 공식강도

## 예측 프로그램 (노트북 `predict()` · HTML 모델)

- 입력: 재료 7종(kg/m³), 목표 강도(MPa, 범위 제한 없음), 재령(기본 28일)
- 출력: 달성 확률, 예상 강도 μ ± σ, 공식 예측 강도, W/B, 판정 (80% 이상 "시험해 볼 가치가 높음", 50~80% "가능성 있음", 20~50% "가능성 낮음", 20% 미만 "달성 어려움")
- 선택: fck와 s를 넣으면 배합강도 f<sub>cr</sub>을 계산해 fck 기준·f<sub>cr</sub> 기준 확률을 함께 표시
  - 식: fck ≤ 35이면 max(fck + 1.34s, (fck − 3.5) + 2.33s), fck > 35이면 max(fck + 1.34s, 0.9fck + 2.33s), s가 없으면 fck + 7 / + 8.5 / 1.1fck + 5.0
  - 콘크리트 표준시방서의 배합강도 식으로 알려진 형태이며, **계수는 시방서 원문으로 확인 필요**
- 학습 범위를 벗어난 재료량·재령·W/B는 경고 (목표 강도에는 경고 없음)
- 예시: 시멘트 350, 물 180, 굵은골재 1000, 잔골재 780 (나머지 0), 28일 → 목표 24 MPa 확률 97.2%, 목표 35 MPa 46.5% (예상 강도 34.5 ± 5.5 MPa)

- 엑셀 공식강도·W/B 수식 값이 파이썬 계산과 일치 (최대 차이 10⁻¹³)

## 한계점

1. **확률의 뜻**: 이 확률은 모델의 예측 오차(교차검증으로 잰 σ)를 바탕으로 한 값입니다. 같은 배합을 반복 시험한 기록은 데이터에 아주 적어(배합·재령이 같은 행 53행), 현장 배치마다 생기는 품질 변동은 반영되지 않습니다. 실제 강도 시험을 대신할 수 없습니다.
2. **정규분포 가정**: 오차가 정규분포를 따른다고 보고 확률을 계산합니다. 실제 오차 분포의 꼬리가 더 두꺼우면 아주 높거나 낮은 확률(예: 99%, 1%)은 실제보다 극단적으로 나올 수 있습니다.
3. **해외 실험실 자료**: 어떤 나라의 재료로 만든 시험체인지는 원문에 없습니다(확인 못함). 국내 배합에 쓰려면 국내 시험 자료로 다시 확인해야 합니다.
4. **입력에 없는 요인**: 시멘트 종류, 골재 품질, 양생 온도·습도, 공기량, 시험체 크기가 없습니다.
5. **중복 행 사용**: 요청에 따라 완전 중복 25건도 그대로 썼습니다. 같은 배합은 항상 학습·테스트 한쪽에만 들어가 성능이 부풀려지지는 않지만, 중복된 배합이 학습에서 더 큰 비중을 가집니다.
6. **방법 선택**: 확률 방법을 테스트 성능으로 고르라는 조건을 따랐습니다. 같은 테스트로 고르고 평가했으므로 선택된 방법의 테스트 성능은 아주 조금 좋게 보일 수 있습니다. A1·A2·B1·B2의 차이는 작습니다.
7. **공식 계수**: Abrams 계수는 이 데이터의 학습용 행으로 맞춘 값이라 교과서 계수와 다릅니다. ACI 209 계수(4.0, 0.85)는 습윤양생·1종 시멘트 조건의 값으로 알려져 있으며 원문 확인이 필요합니다.
8. **분할 하나의 결과**: random_state = 42 한 가지 분할의 결과입니다. 앞선 실험에서 분할에 따라 R²가 ±0.04 정도 움직였습니다.
